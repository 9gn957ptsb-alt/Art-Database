# DIRT Drift

A search engine that takes a thing instead of words. Put in a photo of an object, or its name, and it drifts outward
through seven stations: each a concrete, real thing or scene, joined to the one before by exactly one shared quality
(a colour, a texture, a motion, a sound, a place, a rhythm), never the same kind of thing, farther with every step. A
basketball can reach a pelican sitting on a rock out at sea. Each station has a website to visit and search links, and
"Drift from here" goes on from any station, forever.

The drift is drawn as DIRT soil: one region per station in that thing's colours, in a grammar set by the quality that
carried the drift there (rings for sound, flow for motion, strata for time, a horizon for place, grain for texture),
the region before giving way to it in an overspray with their shared colour stitched along the seam. A picture put in
becomes the first region's soil itself.

It runs on claude.ai as https://claude.ai/artifact/CGcFbf5sd8vHP3cKobdv1a, asking Claude through the page's `sample`
capability (on the viewer's own Claude account; the first drift asks for permission). It opens on a worked example
(basketball to the guano islands of Chincha), and after that on the viewer's own last drift.
